# Moodyfy

Moodyfy is an AI-powered mood journaling application that helps users track their emotions, maintain a daily journal, practice gratitude, and gain personalized insights into their emotional well-being. Users can log moods, write reflections, visualize emotional trends, and receive AI-generated analysis to better understand their thoughts and feelings over time.

## Features

- Daily mood tracking
- Personal journaling
- Gratitude journaling
- AI-powered mood and sentiment analysis
- Mood history and emotional trends
- Secure user authentication
- Responsive and user-friendly interface

## Tech Stack

- Frontend: React.js, TypeScript, Redux Toolkit
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT
- AI Integration: Groq API
